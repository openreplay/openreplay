## 1.0.9

Initial release.

- Screen recording with change-driven capture, resolution capping and
  frame dedupe
- Touch, swipe, screen and input events
- `debugPrint` capture, Dart crash reporting, performance metrics
- Network capture with header and body sanitization
- Masking for sensitive widgets and platform views

The version starts at 1.0.9 because OpenReplay ingest rejects mobile trackers
below that.
